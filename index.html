07 • Build Roadmap

Step-by-step system development

මේ order එකෙන් ගියොත් නැවත නැවත rebuild කරන්න අවශ්‍යතාව අඩු වේ.

01

Requirements Finalization

Rules, fields, user roles, workflows, approval rules.

02

Database Design

Tables, relationships, IDs, historical annual structure.

03

Supabase Setup

PostgreSQL database, Authentication, Storage, RLS.

04

Master Data Import

100 GN divisions, initial Society IDs and administrator records.

05

Login & Roles

Super Admin, Balmandalaya, Officers, Societies, Members.

06

Society Registration

Society profile, advisor, committee, members, documents.

07

Member + Committee Management

Member database and annual position history.

08

Monthly Meetings + Reports

Meeting record, attendance, report submission, review and approval.

09

Projects + Documents

Project workflow, files, photos, review and approval.

10

Notifications + Automation

Deadlines, reminders, announcements and alerts.

11

Dashboards + Analytics

Society, Officer and Balmandalaya dashboards.

12

Annual Renewal

Close previous year → open new year → copy/update → approve.

13

Public Website

News, events, approved projects, gallery and announcements.

14

Integration

Public website reads approved/live data from the central system.

15

Testing + Security

Permissions, data isolation, workflow, performance and security tests.

16

Pilot

5–10 societies → feedback → improvements.

17

Production Deploy

Hosting + domain + environment configuration.

18

Full Launch

All 100 societies onboard කිරීම.
